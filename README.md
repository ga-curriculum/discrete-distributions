## Learning Objectives

*After this lesson, students will be able to:*
- Define distribution and random variable.
- Describe the difference between discrete and continuous random variables.
- Describe expected value and variance of a random variable.
- Use probability mass functions (pmfs) and cumulative distribution functions (CDFs) to find probabilities of events.
- Describe and give examples of when to use the following distributions: Discrete Uniform, Bernoulli, Binomial, and Poisson.

## Lesson Outline

> **Lesson Time: ~120 mins**

I. **Introduction**
- What is a random variable?
- What is a distribution?

II. **Calculations on Random Variables**
- Probabilities
- pmfs and CDFs
- Mean/expectation

III. **Random Variable Flashcards**
- (Discrete) Uniform
- Bernoulli
- Binomial
- Poisson
- Extras for fun:
    - Geometric
    - Hypergeometric
    - Multinomial

IV. **Python Practice**
- Random variables in `scipy`
- Simulations and graphing
- Probability calculations
