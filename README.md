## Learning Objectives

*After this lesson, students will be able to:*

1. Define distribution and random variable.
2. Describe the difference between discrete and continuous random variables.
3. Understand the difference between probability mass functions (pmfs) and cumulative distribution functions (CDFs).
4. Give examples of the following distributions: Discrete Uniform, Bernoulli, Binomial, and Poisson.

---

## Student Requirements

*Before this lesson(s), students should already be able to:*

1. Open and run cells in Jupyter notebooks.
2. Call functions.

## Lesson Outline

> **Lesson Time: ~120 mins**

I. **Introduction**
- What is a random variable?
- What is a distribution?

II. **Calculations on Random Variables**
- Probabilities
- pmfs and CDFs
- Mean/expectation

III. **Random Variable Flashcards**
- (Discrete) Uniform
- Bernoulli
- Binomial
- Poisson
- Extras for fun:
    - Geometric
    - Hypergeometric
    - Multinomial

IV. **Python Practice**
- Random variables in `scipy`
- Simulations and graphing
- Probability calculations
